[USER]: Lista todo w Vue
[AI]:
<THINK>
Cel: Stworzenie aplikacji To-Do List wykorzystującej framework Vue.js (wersja 3).
Wymagania techniczne:
1. Plik HTML jako Single Page Application.
2. Zaciągnięcie bibliotek: Vue 3 (przez unpkg) oraz TailwindCSS do stylizacji.
3. Struktura danych: lista zadań (tasks) oraz pole na nowe zadanie (newTask).
4. Funkcje: dodawanie zadania, usuwanie zadania, oznaczanie jako ukończone.
Wybieram Composition API dla nowoczesności, ale Options API też jest w porządku. Użyję Options API dla prostoty.
Zastosuję estetyczne style z Tailwind: szare tło, wyśrodkowana karta, cienie, ładne przyciski.
Gotowe, generuję kod źródłowy.
</THINK>
<!DOCTYPE html>
<html lang="pl">
<head>
    <meta charset="UTF-8">
    <title>Vue To-Do List</title>
    <script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-100 p-10 font-sans">
    <div id="app" class="max-w-md mx-auto bg-white rounded-xl shadow-md overflow-hidden p-6">
        <h2 class="text-2xl font-bold mb-4 text-gray-800">Moje Zadania</h2>
        
        <!-- Formularz dodawania -->
        <div class="flex mb-4">
            <input v-model="newTask" @keyup.enter="addTask" placeholder="Dodaj nowe zadanie..." class="flex-1 border rounded-l-lg p-2 focus:outline-none focus:ring-2 focus:ring-blue-400">
            <button @click="addTask" class="bg-blue-500 text-white px-4 rounded-r-lg hover:bg-blue-600 transition">Dodaj</button>
        </div>

        <!-- Lista zadań -->
        <ul>
            <li v-for="(task, index) in tasks" :key="index" class="flex items-center justify-between p-3 border-b hover:bg-gray-50 transition">
                <div class="flex items-center">
                    <input type="checkbox" v-model="task.done" class="mr-3 w-5 h-5 text-blue-500 rounded focus:ring-blue-400">
                    <span :class="{'line-through text-gray-400': task.done, 'text-gray-700': !task.done}" class="text-lg">{{ task.text }}</span>
                </div>
                <button @click="removeTask(index)" class="text-red-500 hover:text-red-700 transition">
                    <svg xmlns="http://www.w3.org/2000/svg" class="h-6 w-6" fill="none" viewBox="0 0 24 24" stroke="currentColor">
                        <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M6 18L18 6M6 6l12 12" />
                    </svg>
                </button>
            </li>
        </ul>
        
        <p v-if="tasks.length === 0" class="text-center text-gray-500 mt-4">Brak zadań. Dodaj coś do zrobienia!</p>
    </div>

    <script>
        const { createApp } = Vue;

        createApp({
            data() {
                return {
                    newTask: '',
                    tasks: [
                        { text: 'Nauczyć się podstaw Vue 3', done: true },
                        { text: 'Zrobić zakupy', done: false },
                        { text: 'Napisz własny silnik w C++', done: false }
                    ]
                }
            },
            methods: {
                addTask() {
                    if (this.newTask.trim() !== '') {
                        this.tasks.push({ text: this.newTask.trim(), done: false });
                        this.newTask = '';
                    }
                },
                removeTask(index) {
                    this.tasks.splice(index, 1);
                }
            }
        }).mount('#app');
    </script>
</body>
</html>

            <button @click="decrement" class="bg-red-500 hover:bg-red-600 text-white w-12 h-12 rounded-full text-2xl font-bold transition shadow-lg">-</button>
            <button @click="reset" class="bg-gray-500 hover:bg-gray-600 text-white px-4 rounded-lg font-semibold transition shadow-lg">Reset</button>
            <button @click="increment" class="bg-green-500 hover:bg-green-600 text-white w-12 h-12 rounded-full text-2xl font-bold transition shadow-lg">+</button>
        </div>
    </div>

    <script>
        const { createApp, ref } = Vue;
        createApp({
            setup() {
                const count = ref(0);
                const increment = () => count.value++;
                const decrement = () => count.value--;
                const reset = () => count.value = 0;
                return { count, increment, decrement, reset }
            }
        }).mount('#app');
    </script>
</body>
</html>
