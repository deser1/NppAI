# Experimental gated source-byte readout

This implements the [identifier-copy protocol](explicit-identifier-copy-protocol.md)
as a Python-only research model. It changes the output distribution, not just an
attention loss. No plugin default, native runtime or production checkpoint changes.

The frozen dense backbone starts from full-response checkpoint
`161d6303c7e77f005cbabba5a1790b9d6a6dfc1812c121bfbb3f1cb6820e5b1a`.
New query/key projections attend to **user prompt text bytes only**, with causal
masking. Role markers, response bytes, padding and EOS byte zero are ineligible.
Source hidden states are causal too. Probabilities for repeated byte IDs are
summed; a learned sigmoid gate mixes this distribution with the normal vocabulary
distribution. Empty-source queries use exactly the vocabulary path. Gate bounds
are 0.00001–0.99999 when source positions exist; initial gate bias is -4 with zero
weights. No function-name string replacement, reference prefix, oracle position
selection or hard copy rule is used in full decoding.

One predefined recipe is used: 1024 updates, backbone seed 42, new-head seed 4242,
64-dimensional readout, AdamW 0.001, batch 4, clipping 1, context 256, two CPU
threads, the frozen training split with four wording forms, per-draw aliases and
50% original replay by example. The new model trains all backbone/head parameters
using **response next-byte NLL only**, including EOS; there is no auxiliary
alignment loss or name-only reweighting. Initial predictions are recorded
separately because the additional head changes the initial output distribution.
A parameter-count/clipping difference is part of this architectural intervention;
this is not an isolated causal test of a single attention component.

Unchanged control, fresh control repeat and copy training run sequentially on one
host. The control reports must be byte-identical and replay the historical full
replies. Historical weight identity is reported separately; cross-host numeric
identity is not assumed. Source-example schedules and runtime must agree. The
copy model is evaluated after export/load and exact parameter equality checks.

All 164 exposed development/training views from the previous experiment are
recorded with full greedy replies (160 new bytes), names, signatures, syntax,
reference AST/exact matches and retention. Conditional bytes and `def `-scaffolded
name decoding are measured separately. They do not establish autonomous copying
or body correctness. Source masks remain tied to original prompt positions when
the 256-byte decoding window rolls; generated bytes never become copy sources.

After all optimization, both models generate responses for six separately authored
probes in `evaluation/gated-copy-probes-v1`. Their authored cases never enter
training or prompts. Syntax and functional checks use the production restricted
Docker validator, immutable image ID, no host mounts/network/secrets, and bounded
execution. Infrastructure errors abort instead of counting as model failures.
These probes are independent of optimization but correlated with simple-function
families and selected with knowledge of prior limitations; they are not a broad
unbiased holdout. After measurement they become exposed regression probes.

## Experimental bundle and compatibility

`.nppaicopy` is a distinct, versioned ZIP bundle with exactly `base.nppai`,
`head.npz` and `manifest.json`. The manifest requires format/version, component
SHA-256 digests, pinned source identity and `native_compatible: false`.
The head contains four finite FP32 arrays with exact names/shapes. The loader
rejects unknown/duplicate members, oversized entries, changed digests, wrong
versions, invalid tensors and pickle-backed NumPy data. It reads members in memory
without extracting arbitrary paths. ZIP entry timestamps are fixed for stable
serialization. The legacy `.nppai` loader rejects the bundle magic. Do not extract
and deploy the base component alone: it omits the learned readout. The native
engine needs a separate implementation/compatibility review before any promotion.

Implementation: `scripts/gated_copy_model.py`, `scripts/train_gated_copy.py`.
Tests: `tests/test_gated_copy.py`. Workflow: **Paired gated source-byte copy readout**.
Raw evidence and experimental weights are uploaded for 14 days; source checkpoint
retention also bounds reproducibility. No automatic promotion occurs, regardless
of workflow success. A completed experiment can have zero functional passes.

## Observed outcome

Measured run [38849007538](https://github.com/deser1/NppAI/actions/runs/38849007538)
completed on 2026-10-16. All six initial tests passed with actual PyTorch inference,
including causal masking/gradients and bundle round-trip. Both control reports
are byte-identical; historical control weight identity is true in this run.
Source schedules match. The copy bundle was reloaded before all after-scoring,
with exact parameter equality. Separate functional validation used actual Docker
and the container cleanup check passed.

**Both arms remain 0/132 development requested names, full signatures, reference
AST and exact full replies. Both score 0/6 separately authored functional probes.**
No model is promoted and the native/default runtime is unchanged.

| Conditional name-byte group | Control correct / bytes | Copy correct / bytes |
|---|---:|---:|
| Renamed validation (`ev_`) | 44/176 | 56/176 |
| Renamed test (`ev_`) | 69/308 | 88/308 |
| Matched-prefix validation (`nc_`) | 85/176 | 127/176 |
| Matched-prefix test (`nc_`) | 166/308 | 218/308 |

These conditional counts supply prior correct name bytes. Complete conditional
names and separate `def `-scaffolded exact names still score 0/132 development
views. One of 16 renamed training views has all conditional name bytes correct,
but not a correct scaffolded name terminated by `(`. It does not establish free
copying. Original training exact replies are 4/16 control and 5/16 copy. Copy
retains one prior exact hit, loses one and gains four; control retains none,
loses two and gains four. Exposed training gains are not generalization.

Logged first/final training minibatch loss is 1.2386/0.2505 for control versus
1.0356/0.1527 for copy. These are different sampled minibatches, not held-out mean
loss. The initial copy distribution already differs from control; raw before
outputs are retained rather than attributing every difference to training.

The worker stops at the first failure. Valid syntax with a different function name
cannot establish body semantics, and the 18 authored cases were not all invoked.
Test cases never entered model prompts or optimization. This six-probe result is
small and correlated with familiar operation templates, not broad independent
problem accuracy. The probes are exposed regression material after this run.

The copy readout improves some conditional byte counts but does not satisfy the
complete-name or functional acceptance gates. Before scaling full-code training,
measure a dedicated training-only identifier-copy curriculum and gate behavior;
keep independent evaluation reserved and require original-task retention. No
coefficient/seed/checkpoint search was performed in this experiment.

Head array headers, exact shapes, dtypes and payload lengths are checked before NumPy allocates an array; oversized declared shapes and trailing data are rejected.
