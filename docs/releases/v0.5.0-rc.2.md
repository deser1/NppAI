# NppAI v0.5.0-rc.2

This experimental integration prerelease fixes the collapsed review diff found
while recording a real request in v0.5.0-rc.1. LF/CRLF/CR are normalized only in
the Win32 review display; actual model output and patch bytes are unchanged.

## Downloads and startup

Download the plugin ZIP matching your Notepad++ architecture, `NppAI-service.zip`
and the separate `NppAI-research-staged-mix.nppai`. Close the editor before
replacing the `NppAI` plugin directory and keep a backup of the previous version.
Extract the service ZIP to a writable folder; no repository checkout is needed.
Compare SHA-256 values with `SHA256SUMS.txt`.

Open PowerShell in the extracted service folder:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-inference.txt
.\.venv\Scripts\python.exe scripts\start_nppai.py --model "C:\Models\NppAI-research-staged-mix.nppai" --notepad "C:\Program Files\Notepad++\notepad++.exe"
```

Keep the console open and follow `docs/notepad-setup-pl.md` for Docker Desktop
and authored tests. Apply is disabled until the required validation passes.

## Actual demonstration and checks

`notepad-live-demo.gif` records the actual candidate DLL, official portable
Notepad++ 8.9.8.1 and own-model service from the extracted ZIP. It sends the
documented Polish factorial prompt, receives a real model HTTP 200, shows the
proposal/blocked review and scrolls to its actual code. No output is substituted.
The report retains the exact proposal and its AST syntax error; code is never
executed or applied in this demo. No Docker validator is configured in it.

The unchanged research model returns invalid code. Its retained functional
quality is still **0/12**; this recording demonstrates integration, readable
failure and Apply protection, not successful factorial generation. The function
signature is supplied by the application. See `MODEL_CARD.md` for provenance.

Publication requires three architecture packages, native tests including actual
review-control line counts, real x64 editor generation, recording/report/asset
hash agreement and successful CI_build on the exact source commit.

Human upgrade behavior, Docker Desktop on the user's machine, validated GUI
Apply, and actual x86/ARM64 editor execution remain unverified. The earlier
[release recording and raw failures](https://github.com/deser1/NppAI/blob/main/docs/live-generation-demo.md)
are retained separately from the corrected candidate demonstration.
